# Studio Image Folder Directories

You can store static studio photos directly in these folders:

- `/public/images/gallery/` -> Finished handcrafted portraits for the public gallery.
- `/public/images/showcase/` -> Before (customer reference photo) & After (finished artwork) comparison pairs.
- `/public/images/styles/` -> Technique and medium sample photos (Pencil, Charcoal, Watercolor, Oil, Color Pencil, Digital).
- `/public/images/banners/` -> Hero header graphics, atelier workshop banners, and marketing visuals.
- `/public/images/artists/` -> Master artist profile pictures and staff avatars.
- `/public/images/reviews/` -> Framed customer photos, unboxing snapshots, and testimonial proofs.

---
### Referencing local folder images in code or Admin CMS:
Any file placed in `/public/images/gallery/my-photo.jpg` can be accessed via:
`/images/gallery/my-photo.jpg`
